# 492CPE Industrial Process Simulations

Educational software prototypes for industrial automation and manufacturing systems.

## Assignment 1 — SmartMix Process Simulator

An interactive batch mixing process simulator with live sensor readings, process fault scenarios, and bounded control recommendations.

- [Open the live SmartMix simulator](https://sahran1.github.io/-industrial-process/)
- [View the source](index.html)

## Assignment 2 — FactoryTwin Bottling Line Digital Twin

A software-based digital twin for a virtual beverage packaging line. It analyzes performance, estimates equipment risks, and compares product lifecycle scenarios.

- [Open the live FactoryTwin app](https://sahran1.github.io/-industrial-process/digital-twin/)
- [View the digital twin source and model notes](digital-twin/)

All production data and lifecycle figures are illustrative coursework assumptions. Neither prototype connects to physical equipment.
